# London Trip · Simple Past

Lernwebseite für Englisch in Klasse 6 und 7. Nach dem Entpacken lässt sich `index.html` lokal im Browser öffnen.

## Auf GitHub Pages veröffentlichen

1. ZIP entpacken. Auf GitHub ein Repository anlegen, zum Beispiel `simple-past-london-trip`.
2. Im Repository **Add file → Upload files** wählen. Die entpackten Dateien direkt auf die oberste Ebene hochladen. `index.html`, `style.css`, `tasks.js` und `app.js` müssen nebeneinander liegen.
3. Auf **Commit changes** klicken. In **Settings → Pages** unter **Build and deployment** die Quelle **Deploy from a branch** wählen. **main** und **/(root)** auswählen und speichern.
4. Sobald GitHub Pages die veröffentlichte Adresse anzeigt, die Webseite über **Visit site** öffnen und testen. Das ist der Link für die Klasse.

Die Seite speichert Übungsfortschritte während des geöffneten Besuchs. Ein Neuladen beginnt eine neue Sitzung.
